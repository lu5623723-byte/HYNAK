## 开始使用

1. 安装 **Python 3.11 或更高版本**。Windows 安装时勾选 **Add Python to PATH**。首次启动需要网络下载依赖。
2. macOS 双击 `start-mac.command`；Windows 双击 `start-windows.bat`。Mac 如因下载文件保护无法运行，请在 Finder 中右键打开并按系统提示操作。
3. 浏览器自动打开 `http://127.0.0.1:8765`。首个页面创建管理员，密码至少10位。
4. 保留启动窗口；关闭窗口或按 Ctrl+C 停止服务。再次双击，数据保持不变。

默认数据目录：macOS `/Users/你的用户名/.hynak`，Windows `C:\Users\你的用户名\.hynak`，包括 `hynak.sqlite3`、私有 `attachments/` 和 `backups/`。程序目录更新不会覆盖该目录。可复制 `.env.example` 为 `.env`，设置 `HYNAK_DATA_DIR`、`PORT` 和 `PUBLIC_BASE_URL`。修改端口时同步修改 URL。只保留一个本地运行实例。

## 首次业务配置顺序

经销商资料支持CNPJ及巴西店铺地址，按州（UF）→城市（Município）→街道/门牌号/区/补充信息/CEP填写。州与城市目录为IBGE本地快照，支持离线选择；CNPJ兼容数字与字母数字格式并校验校验位。旧资料未填写的新字段保留为空。

1. **账号与权限**：先建销售、仓库、财务账号。销售佣金比例默认0；请填实际批准的比例，单位基点（例如300=3%，仅说明单位）。
2. **经销商**：建经销商、WhatsApp国家码号码、沟通语言和责任销售。再为经销商创建主账号，并选择关联经销商。
3. **商品与价格**：录入真实SKU及标准批发价。
4. **库存 / 寄售**：两个独立入口。库存先选择一级/二级仓，再选择具体仓库；寄售先选择经销商，再选择其名下寄售点。选择完成后才展示对应的余额、出库交付、报售和流水；切换级别或经销商会清空地点及搜索条件。管理员和仓管仍可新增、维护仓库档案，通过核实期初或Excel模板录入真实余额。
5. **应收与实收 → 收款账户**：录入真实银行账户及别名。TF与xt自动同账户；xiaolu与卢禁止未经核实合并。

## 可运行的业务闭环

经销商下单界面使用“新建采购订单 / 采购日期 / 采购类型”，采购类型固定现付，提供备注，不提供促销选择或70/30条款。促销方案仅管理员可在新建或修订报价时选择；销售与经销商新建订单默认标准价，后端拒绝越权促销请求。历史订单已批准的促销保持原记录。

经销商“商品与价格”页显示在售车型、采购价、可用库存和供货状态，与管理员库存模块共用库存流水。可用数量汇总一级/二级仓各自扣除锁货后的非负余额，不包括经销商寄售库存。进入商品页、页面恢复显示或点击“刷新库存”时更新；页面停留期间每30秒自动更新。更新失败保留上次结果并显示提示。缺货商品可预订，停售商品不出现在经销商商品列表。

经销商业务概览分别显示本月已采购订单笔数与采购金额；自定义起止日期可查询期间下单笔数和金额。统一按圣保罗时区的订单生效日期统计，仅包含当前业务的已生效、部分出库、全部出库和已完成订单，包含起止日期当天。草稿、待审核、待确认、撤销、拒绝、期初应收与寄售发货不计入。金额为订单总额（含订单运费，如有），核销付款不减少采购统计；接口只查询当前登录经销商。

新建订单须填写**销售日期**。经销商仍只能现付，须付款时间及水单。销售可选择**现付、寄售、其他**，并填写自定单价；自定价格只能由管理员审核批准。销售的寄售/其他订单提交后待管理员审核，通过后生效，不提供财务审批权限。寄售须付款到期日，其他须付款到期日和备注说明。现付标准价订单由财务核实足额到账后生效；销售自定价现付订单先管理员批准价格，再由财务核实足额到账后生效并核销。新生效寄售订单按整单金额形成应收，后续关联报售仅扣库存、不重复记应收；历史未关联库存保留报售结算；其他审核生效后形成应收，不产生虚构实收。

- **经销商自行下单**：经销商登录→选车型数量→填写付款时间并上传水单→待财务审核→财务核实银行足额到账→自动生效、产生应收并自动核销付款，无管理员价格审核或二次经销商确认。
- **销售代拟**：销售代建现付订单→上传完整付款信息与凭证→待财务审核→财务核实足额到账后自动生效并核销付款、锁定可用库存。新现付单不使用客户确认链接。管理员可在核实前修订价格；已核实部分款项后须财务人工复核，不允许直接改价或撤销。管理员寄售单与历史普通批发单保留各自流程。
- **价格**：Demo=标准价×80%；10+1同SKU25付费赠2台独立R$0行；不能叠加。管理员特殊改价要填写原因。
- **库存**：入库、调拨、寄售发出/退回写不可编辑流水。调拨不产生应收；新寄售订单在生效时建立整单应收，交车不重复计应收。创建出库单扣库存；实际提货后在库存页确认交付。缺SN填写异常，不造号。撤销未提货可回补，已交付由管理员登记实际退回。
- **寄售售出**：整单结算库存报售时须选择原寄售订单→管理员确认→仅扣售出数量，不另建订单或应收；历史未关联库存继续报售后结算，重复确认幂等。
- **收款**：订单详情上传PNG/JPEG/PDF付款凭证，最多5MB→仅为待核实申报→财务独立核对银行，记录实际金额/日期/真实账户/参考号并关联订单付款凭证。待审核现付订单足额到账时自动生效并分配款项；不足额继续待审核，追加转账须上传新的银行流水凭证，多余款项保留预存款。历史应收可人工分配到一单或多单。截图不改变实收；超额款保留预存款。期初预存款可单独分配。
- **催收**：按经销商、销售、最少逾期天数、最小欠款筛选，记录备注/下次日期。WhatsApp按钮打开对应语言消息草稿，员工手动发送。
- **佣金**：所有车辆含赠品全部实际交付、车款全额分配实收后，由管理员审核保存基数/比例/金额快照，财务整笔记录人工结算。货运费与赠品不计提。按审核月汇总。退车/跨期异常先记录负数调整并标记人工复核，不自动退款/追佣。
- **撤销/冲销**：管理员在订单详情填写原因调整应收；未交付无已分配实收时可撤单。已分配款或已结算佣金涉及退款，请保留记录并人工复核，首版不提供自动退款网关或撤销银行交易。

锁货默认72自然小时；每5分钟、服务启动及业务请求时清理。无任何**已分配银行核实实收**时释放；截图无效。已核实款仅停留经销商余额、尚未分配到订单时，不代表该订单已收。释放后管理员可重新分配库存；无货订单仍可提交。
