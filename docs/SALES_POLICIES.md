# 销售政策与发布

管理员在“销售政策”中编辑名称、内容、有效期和计价规则，发布后销售端每30秒更新。标准价、买10送1仍可用于销售的“其他”订单，不可叠加；合规价格直接生效。自定义价格例外逐单由管理员审核。现付仍须财务核实足额到账后生效，寄售发货仍须管理员审核。

## Demo：正常下单，随后逐车型勾选

经销商新建采购订单只显示正常价格，按正常价提交付款时间及银行水单。系统不会自动折价，经销商不能选择 Demo。

销售或管理员打开未生效订单的详情，点击“设置 Demo 计划”，逐车型勾选。勾选后，该行按订单保存的标准单价八折计算（分为单位四舍五入）；其他车型保留原价及数量。无需管理员先发布 Demo 政策，也无额外政策申请。不能与买10送1叠加，寄售发货不适用采购优惠。销售只可操作自己负责的经销商。

**每个经销商的每种车型仅可享受一次 Demo；后续再次采购同一车型不再享受。**正常价历史采购不会占用 Demo 机会。已生效且未整单撤销的历史 Demo 也计入，换月份或换方案名称不重置。待处理订单的勾选会暂时锁住名额，其他订单不能重复勾选；生效时再次校验。未生效订单取消勾选、被拒绝、过期或整单撤销后释放；已生效订单整单撤销须符合原有退款、库存及佣金约束。

Demo 只允许在订单生效前、尚无银行核实到账时修改（包括部分到账也不能直接修改）。修改记录操作人、版本、车型及价格变化，并撤销旧确认链接；已生效订单不直接改价。未勾选车型的自定义价例外仍须管理员审核。现付订单调整 Demo 后继续等待财务核实，原水单和申报金额保留，不改写已发生的付款；超出调整后订单总额的实际付款留为经销商预存款。

已有整单 Demo 政策记录和历史报价保留用于兼容及审计，不再作为新订单的 Demo 选择入口。新流程通过订单详情独立设置，无需月度 Demo 方案。

管理员账号入口为“账号与权限”→“新增账号”→选择 admin；首次安装使用初始化页面创建首位管理员。
