# Dashboard 自定义查看

在「业务概览 → 查看范围与指标」中选择起止日期，或使用本月、上月、今天、全部时间。默认本月 1 日至今天；所有日期按巴西圣保罗时区计算，包含起止当天。

可以组合筛选经销商、责任销售、销售类型、订单状态和付款状态。日期口径可切换订单生效日期、采购/销售日期、创建日期或付款到期日。点击「应用筛选」后，指标、订单明细、欠款排名及销售汇总一起更新。待审核订单没有生效日期，查看它们时应使用创建日期或全部时间。

新增「车型销售排名」和「经销商采购排名」，使用同一组日期及业务筛选。车型默认按销量排名，经销商默认按采购商品金额排名；两张榜单均可独立切换数量、商品金额或订单笔数，显示前 10 名、前 20 名或全部。

两个榜单都可通过「展示方式」独立选择**柱状图、趋势图、表格**。默认使用柱状图比较排名；趋势图按上方所选订单日期口径展示各车型/经销商每期的成交数量、商品金额或订单笔数。汇总周期可选自动、按天、按周、按月；周从星期一开始，首尾周期仅统计实际选定的日期范围。无成交的周期补零；单个周期显示为一个数据点。较长跨度自动合并周期并标明实际汇总口径，避免遗漏数据。

趋势图默认展示当前排名前五项，可点击图例选择最多十条曲线，并悬停数据点查看日期与数值。图例显隐只改变展示，不改变统计范围。切换日期后重新选择当前前五项。展示方式、指标、名次范围和周期偏好按登录用户保存在当前浏览器。订单缺少所选日期时，在趋势中标注未包含的笔数，表格和柱状图仍保留该订单的汇总量。

排行榜只统计与生效销售订单指标相同的有效订单。销量按非赠品行数量汇总，商品金额按订单保存的成交单价 × 数量计算，包含 Demo 折扣，不随后来标准价的修改变化；赠品和运费排除。多 SKU 订单在经销商订单笔数中只计一笔，同一车型跨订单合并。经销商排名反映向 HYNAK 采购的情况。销售和经销商只能看到自身权限范围内的排名。无匹配记录时显示空结果。

「自定义显示指标」支持显示或隐藏未收回、实收、逾期、生效订单笔数、生效订单金额、应收总额和待处理笔数。指标选择保存在当前浏览器，按登录用户分别保存。

| 指标 | 口径 |
| --- | --- |
| 尚未收回 / 待核销应付款 | 所选订单目前的调整后应收，减去已核实且已抵扣到本单的款项；每单最低为零 |
| 已逾期金额 | 所选订单中，截至今天付款到期日已过的当前未付余额 |
| 期间银行核实实收 | 实际到账日期在所选期间、属于所选经销商/责任销售的已核实银行入账，含充值；不含待核实水单 |
| 类型/状态限定后的实收 | 再按订单销售类型、订单状态或付款状态筛选时，只计可归属到这些订单条件的实收；未分配充值不计入，部分分配按实际归属金额计，不重复汇总整笔充值 |
| 期间生效订单数和金额 | 所选订单中已生效的销售订单；延续原采购统计口径，不计草稿、待审核、待确认、撤销、拒绝、期初应收及寄售发货。寄售报售生成的销售结算订单计入 |
| 待处理订单数 | 所选订单中的草稿、待管理员审核、待财务审核及待客户确认订单 |

未收回、逾期和应收等余额为查询时的**当前余额**，不是历史日期的余额快照。订单日期条件与银行实际到账日期分别作用于订单和银行实收。例如十月订单在十一月收到的款项，计入十一月实收。页面提供统计说明和实收明细以核对差异。

账户可用余额及库存快览仍展示当前状态，并明确标注不受订单日期筛选影响。

API：`GET /api/dashboard-summary`。参数为 `start`、`end`、`basis`、`dealer_id`、`sales_id`、`sale_type`、`status`、`payment_status`；两个日期同时为空表示全部时间。接口复用登录账号的数据可见范围，销售仅看所辖经销商，经销商仅看自己，越权指定 ID 会被拒绝。

验证：`tests/test_dashboard.py` 覆盖日期边界、当前欠款、跨期收款、期初与寄售排除、分配去重、待生效订单归属、空结果、参数校验和角色隔离。浏览器验证了日期组合筛选、类型/状态实收归属、指标选择保留、无效日期、空结果及页面布局。

排行榜补充验证：多 SKU 汇总、赠品/运费排除、Demo 成交金额、历史价格不变、订单笔数去重、日期和业务筛选、角色隔离；浏览器验证排序切换、上月/自定义日期联动与空结果。

图表验证：`tests/test_dashboard.py` 检查每日趋势与排行榜一致、圣保罗时区边界、多 SKU 订单计数去重、日期口径切换和权限隔离。`node tests/dashboard_charts.test.cjs` 检查日期补零、周/月汇总、超长跨度合并保留总量、单点图、零值与名称转义。图表直接使用本地 HTML/SVG 渲染，不依赖外部图表服务。
