## 本次发现及修复

初始专项测试为30通过、2失败。经销商接口原本返回其客户对应的内部催收备注，并在订单对象中包含内部佣金字段；库存导出原本带有内部流水sheet。这些没有导致跨经销商订单读取，但超出了经销商界面所需的信息范围。本次已在后端裁剪，而非只隐藏按钮；无关员工目录也仅保留关联责任销售。
