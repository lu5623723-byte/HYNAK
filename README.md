# HYNAK 巴西订单、库存与回款系统

基于轻量版 PRD 的本地 MVP。真实 FastAPI 后端、SQLAlchemy 数据库、私有付款附件；金额以整数分记账。界面支持中文、巴西葡语、英文。**交付不含真实客户/银行/期初数据，也不预置管理员密码。**

## 开始使用

1. 安装 **Python 3.11 或更高版本**。Windows 安装时勾选 **Add Python to PATH**。首次启动需要网络下载依赖。
2. macOS 双击 `start-mac.command`；Windows 双击 `start-windows.bat`。Mac 如因下载文件保护无法运行，请在 Finder 中右键打开并按系统提示操作。
3. 浏览器自动打开 `http://127.0.0.1:8765`。首个页面创建管理员，密码至少10位。
4. 保留启动窗口；关闭窗口或按 Ctrl+C 停止服务。再次双击，数据保持不变。

默认数据目录：macOS `/Users/你的用户名/.hynak`，Windows `C:\Users\你的用户名\.hynak`，包括 `hynak.sqlite3`、私有 `attachments/` 和 `backups/`。程序目录更新不会覆盖该目录。可复制 `.env.example` 为 `.env`，设置 `HYNAK_DATA_DIR`、`PORT` 和 `PUBLIC_BASE_URL`。修改端口时同步修改 URL。只保留一个本地运行实例。

## 首次业务配置顺序

经销商资料支持CNPJ及巴西店铺地址，按州（UF）→城市（Município）→街道/门牌号/区/补充信息/CEP填写。州与城市目录为IBGE本地快照，支持离线选择；CNPJ兼容数字与字母数字格式并校验校验位。旧资料未填写的新字段保留为空。

1. **账号与权限**：先建销售、仓库、财务账号。销售佣金比例默认0；请填实际批准的比例，单位基点（例如300=3%，仅说明单位）。
2. **经销商**：建经销商、WhatsApp国家码号码、沟通语言和责任销售。再为经销商创建主账号，并选择关联经销商。
3. **商品与价格**：录入真实SKU及标准批发价。
4. **库存与寄售**：建立一级/二级仓和经销商寄售位置，通过核实期初或Excel模板录入真实余额。
5. **应收与实收 → 收款账户**：录入真实银行账户及别名。账户别名请在核实后维护。

## 可运行的业务闭环

新建订单须填写**销售日期**。**经销商只能现付，必须填写付款时间并上传付款水单（PNG/JPEG/PDF，≤5MB）；寄售订单只能由管理员创建**，管理员填写经销商付款到期日。销售新建页面仅提供现付。水单仅为待核实申报，财务确认后才计入实收。寄售订单发出不产生应收，确认报售后形成应收。

- **经销商自行下单**：经销商登录→选车型数量→提交→管理员审核最终报价→立即生效并产生应收，无二次经销商确认。
- **销售代拟**：销售创建草稿→订单详情“提交内部审核”→管理员最终价格审核→销售生成/复制确认链接→客户主动确认→产生应收及有货部分锁货。修订报价增加版本并撤销旧链接；生效后禁止直接改价。
- **价格**：Demo=标准价×80%；10+1同SKU25付费赠2台独立R$0行；不能叠加。管理员特殊改价要填写原因。
- **库存**：入库、调拨、寄售发出/退回写不可编辑流水。调拨和寄售交车不产生应收。创建出库单扣库存；实际提货后在库存页确认交付。缺SN填写异常，不造号。撤销未提货可回补，已交付由管理员登记实际退回。
- **寄售售出**：经销商报售→管理员确认价格和到期日→仅售出数量扣寄售库存、生成应收；重复确认幂等。
- **收款**：订单详情上传PNG/JPEG/PDF付款凭证，最多5MB→仅为待核实申报→财务独立核对银行，记录实际金额/日期/真实账户/参考号→分配到一单或多单。截图不改变实收；超额款保留预存款。期初预存款可单独分配。
- **催收**：按经销商、销售、最少逾期天数、最小欠款筛选，记录备注/下次日期。WhatsApp按钮打开对应语言消息草稿，员工手动发送。
- **佣金**：所有车辆含赠品全部实际交付、车款全额分配实收后，由管理员审核保存基数/比例/金额快照，财务整笔记录人工结算。货运费与赠品不计提。按审核月汇总。退车/跨期异常先记录负数调整并标记人工复核，不自动退款/追佣。
- **撤销/冲销**：管理员在订单详情填写原因调整应收；未交付无已分配实收时可撤单。已分配款或已结算佣金涉及退款，请保留记录并人工复核，首版不提供自动退款网关或撤销银行交易。

锁货默认72自然小时；每5分钟、服务启动及业务请求时清理。无任何**已分配银行核实实收**时释放；截图无效。已核实款仅停留经销商余额、尚未分配到订单时，不代表该订单已收。释放后管理员可重新分配库存；无货订单仍可提交。

## 开发与测试

```sh
python -m venv .venv
# macOS/Linux: .venv/bin/python；Windows: .venv\Scripts\python.exe
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python manage.py migrate
.venv/bin/python -m pytest tests -q
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8765 --no-access-log
```

测试自动创建独立临时数据库，绝不写正式数据。数据库schema版本1、2、3，由 `manage.py migrate` 创建表/索引/不可变流水触发器并保留旧订单升级字段。下一版本有字段变更时须新增显式迁移，不可仅依靠 `create_all`。
