# 最新补充：2026-10-31 销售类型、自定价格与管理员审批

销售可选现付、寄售、其他，并填写自定单价。自定价格须由管理员批准，经销商不可自行改价或新建非现付订单。销售寄售/其他由管理员审核生效，财务无此审批权限；寄售必填销售日期及付款到期日，其他还必填备注说明。自定价现付订单先待管理员批准价格，再待财务核实足额到账才生效。修订不能跳过审核；银行收款不能在价格批准前核实。管理员审核不虚增实收。下文冲突的历史规则均由本补充替代。

# 最新补充：2026-10-31 财务核实后现付订单生效

经销商与销售新建的现付订单均为待财务审核。必须有采购/销售日期、付款时间和私有付款凭证；finance账号通过关联凭证核实真实银行到账，足额后同一事务自动生效并核销款项，不足额继续待审核。管理员价格审核与确认链接均不能使现付单生效。管理员不能代替finance核实待审核现付订单。

“分配实收”允许管理员和财务操作：将同一经销商的已核实到账或期初预存款抵扣已有应收订单，可分配到一单或多单，不得超过可用款项或订单欠款。记录操作人并防止重复提交；此权限不能使待财务审核的现付订单生效。
