# 2026-10-30 最新下单权限

本规则按用户最新指示替代先前允许经销商自行选择寄售的规则。

| 角色 | 新建现付 | 新建寄售 |
|---|---|---|
| 管理员 | 允许，须付款时间及水单 | 允许，须销售日期及付款到期日 |
| 销售 | 允许，页面仅现付 | 禁止 |
| 经销商 | 允许，只能现付，须付款时间及水单 | 禁止 |
| 财务/仓管 | 禁止 | 禁止 |

前端按角色生成可选类型，非管理员新建页面默认现付。后端服务层和JSON/multipart接口同时校验，不依赖按钮是否可见。经销商遗漏销售类型、传WHOLESALE、伪造role=admin或cash_proof字段，都不能绕过现付/附件要求。权限校验在读取旧幂等响应之前执行，旧寄售请求也不会通过缓存重新获准。

管理员建立寄售单后仍按原价格审核/经销商确认流程生效；经销商可以查看自身历史订单、库存并上报寄售已售数量，销售可继续处理其负责客户的既有报价。此限制针对新建订单，不删除、不转换已有订单，不改库存和银行金额。水单仍仅为待核实付款申报。

首次初始化测试环境的样例订单改用现付，并附明确的占位测试水单；不生成虚构银行实收。已有测试库不会重新初始化或覆盖。
