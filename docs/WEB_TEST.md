# HTML网页版测试

当前浏览器测试入口：http://127.0.0.1:8765/

测试账号：admin（管理员）、sales（销售）、dealer（经销商）、finance（财务）、warehouse（仓管）。密码统一为 `Web-test-2026`。这些公开测试凭据只在显式本机测试模式创建，正常启动不预置账号。

本机测试模式启动：Mac双击 `start-web-test-mac.command`，Windows双击 `start-web-test-windows.bat`。首次安装与普通版本相同，需要Python 3.11+和联网安装依赖。测试模式默认数据目录为用户目录下`.hynak-web-test`，正式版本仍使用`.hynak`；互相独立。重复启动不会清空已有测试操作。

本次正在运行的服务使用当前工作区 `work/web-test-data`。可下载的 `HYNAK_网页版测试.html` 是本地后端的浏览器入口，后端启动后点击“打开测试工作台”。HTML文件不能代替数据库服务，首次启动时需保持服务窗口运行。

预置：3种商品、2个经销商、一级/二级仓与寄售点、4张不同阶段订单、待确认的寄售报售。库存为明确测试期初，没有预置银行实收。所有页面标记测试环境；这些数据不代表真实业务。

测试服务仅允许loopback PUBLIC_BASE_URL。没有新增公网部署、自动WhatsApp发送或真实付款能力。
