# 第二阶段与当前验收限制

本版以轻量PRD为范围，以下不属于已完成生产能力：

- 9张原Excel逐行历史业务重建、成本归集、完整序列号生命周期、FIFO、税务/物流/银行API。
- 多门店经销商账号、完整高级RBAC、多人佣金、跨产品比例与自动追佣。
- 自动退款、自动撤销银行实收/分配、工资支付网关。退款或跨期异常留原始记录、佣金负数调整/人工复核，财务离线执行真实资金操作。
- 自动WhatsApp发送、营销触达、PWA或原生Mac/Windows安装器。
- 云端数据库自动迁移、备份调度管理界面、生产监控平台。

## 实际待验证 / 待业务输入

- Windows电脑的首次安装、双击启动、关机重启、附件与备份恢复。
- 云端Docker/Caddy/PostgreSQL真实部署、证书签发、备份定时执行、隔离恢复、异地手机确认U17。
- 业务方提供且核实：切换日、车型标准价、经销商/销售归属、库存、未结清应收、预存款、真实收款账户和佣金比例。

## 当前规模与界面限制

- 本地SQLite只支持单进程服务，业务写串行化；不做多节点高并发。
- 关键页面支持中/葡/英；部分后端错误采用中文/葡语双语，审计动作代码保留技术名。
- 页面搜索/分页在已经按后端对象权限过滤的结果集内完成；库存页显示最近2000条流水，审计页最近300条。XLSX库存流水导出没有这两个界面截断限制。
- 导入为新增期初批次，不用模板覆盖现有SKU/客户；待核实行需整理为单独后续批次。不同内容会视为不同批次，仍需业务核对同一快照不得重加。
- 佣金人工调整进入待复核，不自动重算/追回已付款。银行原始实收和分配流水不可删除。
